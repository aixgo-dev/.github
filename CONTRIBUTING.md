# Contributing to Aixgo

Thanks for your interest. This file applies to every repository in the aixgo-dev org unless that repository has its own contributing guide.

## Before you start

- Open an issue first for anything sizable, so we can agree on the approach before you write code.
- Small fixes, such as typos, docs, and obvious bugs, are welcome as pull requests without an issue.

## Before you submit

- Run the repository's tests and `make check` (or the equivalent in its README) and make sure they pass.
- Keep the change focused and describe what it does and why.

## Aixgo Code

[aixgo-dev/code](https://github.com/aixgo-dev/code) does not currently accept external code contributions. Issues are welcome.

## Aixgo framework

For aixgo specifics, see the [aixgo contributing guide](https://github.com/aixgo-dev/aixgo/blob/main/docs/CONTRIBUTING.md).

## License

## Security

Do not report vulnerabilities in issues or pull requests. See [SECURITY.md](SECURITY.md).
