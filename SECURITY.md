# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

- Use GitHub private vulnerability reporting on the affected repository (Security tab, "Report a vulnerability").
- Or email team@aixgo.dev.

Include the repository, the version, and steps to reproduce.

We aim to acknowledge reports within a few days. We do not promise a fixed response or fix time.

## Supported versions

We support the latest release of each project. Please confirm the issue still exists on the latest release before you report it.
